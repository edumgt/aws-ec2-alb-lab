# Lab: Financial Engineering RAG with Python

금융공학(리스크, 포트폴리오, 파생상품) 텍스트를 대상으로 **RAG(Retrieval-Augmented Generation)** 파이프라인을 직접 구성하는 실습입니다.  
외부 LLM/벡터DB 없이도 동작하는 순수 Python 예제로, RAG 핵심 흐름(문서 적재 → 청킹 → 검색 → 근거 기반 응답)을 이해하는 데 초점을 둡니다.

## 포함 파일
- `financial_rag_lab.py`: 금융공학 문서 인덱싱/검색/응답 생성 CLI
- `data/*.md`: 실습용 금융공학 샘플 문서

## 학습 목표
- 금융 도메인 지식을 RAG용 문서로 구조화하는 방법 익히기
- 질의와 문서 청크 간 유사도 기반 검색 구현
- 응답에 근거 문서(출처)를 함께 제시하는 방식 학습
- 추후 Bedrock/Claude 연계형 고급 RAG로 확장할 준비

## 권장 커리큘럼 (8개 모듈)
| 모듈 | 주제 | 결과물 |
|---|---|---|
| 1 | 금융공학 RAG 문제정의 (사용자 질문 유형 정의) | 질의 카테고리 표(리스크/자산배분/옵션) |
| 2 | 데이터 설계 (리서치 노트, 정책 문서, 강의노트 수집) | 도메인 코퍼스 디렉터리 구조 |
| 3 | 청킹 전략 비교 (문단/슬라이딩 윈도우) | 청크 크기별 검색 성능 비교표 |
| 4 | 검색 랭킹 (TF-IDF 기반) | Top-k 검색 결과 로그 |
| 5 | 근거 기반 응답 템플릿 설계 | 출처 포함 답변 포맷 |
| 6 | 평가 지표 설계 (정확도/근거 적합성) | 평가 체크리스트 |
| 7 | 프롬프트 개선 실습 (요약/비교/권고 유형) | 질문 템플릿 세트 |
| 8 | AWS 확장 (Bedrock + OpenSearch Serverless) | 아키텍처 설계 초안 |

## 실습 시나리오
### Lab A — 리스크 관리 질의응답
- 목표: "VaR를 줄이려면?" 같은 질문에 관련 근거 문단을 인용한 응답 생성

### Lab B — 포트폴리오 리밸런싱 코치
- 목표: 변동성 증가 시 분산투자·헤지 관련 정책 문서 검색

### Lab C — 옵션 전략 학습 도우미
- 목표: 델타/감마/베가 설명을 근거와 함께 안내

## 실행 방법
```bash
python3 ai/financial-rag-python/financial_rag_lab.py \
  --query "금리 상승기에 채권 비중을 줄이는 이유는?" \
  --top-k 3
```

### 옵션
- `--data-dir`: 문서 폴더 경로 (기본: `ai/financial-rag-python/data`)
- `--query`: 사용자 질문
- `--top-k`: 반환할 근거 청크 개수
- `--max-chars`: 청크 길이(문자) 상한

## 과제 아이디어
1. 문서에 ETF 팩트시트/리서치 PDF 요약본을 추가해 검색 품질 개선
2. 질문 타입별 응답 템플릿(정의형/비교형/추천형) 분리
3. `boto3` 기반 Bedrock 호출을 붙여 생성 응답 품질 향상
4. 검색 단계에 메타데이터 필터(자산군, 시장국면, 위험등급) 추가
